# Маҷмааи истиқоматӣ — 3D-сайт жилого комплекса

3D-сайт ЖК на ул. Т. Зехни (Душанбе), 11 блоков по генплану заказчика. Сделан студией Jomi Studio
на коде сайта «Али Бинокор» (`~/Desktop/Али_Бинокор_3D/site`).

**Этап 27.10.2026:** блок К построен полностью снаружи. Остальные 10 блоков (А–И, Л, М), детсад,
телестудия и административное здание стоят на своих местах белыми макетами своего размера.
Квартир, планировок и прогулки внутри пока нет. Языки: русский и таджикский. Цен и статусов нет.

Материалы заказчика лежат вне сайта: `../00_Материалы_клиента/` (PDF, рендеры 3–11, генплан, листы планов).

## Откуда что взято

- **Генплан** (`tools/mi/genplan.py` → `build/genplan.json`): лист 2 PDF векторный, каждая зона
  залита цветом своей легенды. Скрипт читает контуры прямо из PDF: дороги, плитку, дорожки, газоны,
  площадки, корты, парковочные места, существующие дома (этажность — по надписи на доме), блоки
  с буквой и этажностью («18/20», «16/18»). Масштаб: глубина каждого блока 35,93 pt = 22,4 м по планам.
  Начало координат — центр блока К.
- **Планы блока К** (`tools/mi/plans.py` → `build/plan_K.json`): контуры 1-го, 2-го и типового этажей
  (листы 23, 29, 32), шаг осей 7 500 мм = 136,2 pt.
- **Фасады блока К** сняты с рендеров 9 и 10 в метрах (`tools/mi/rectify.py`: фасад разворачивается
  на плоскость по четырём углам). Этажи: 1-й 0, 2-й +5,1 (по плану), 3-й +9,7, дальше 3,0 м
  (по рендерам: плиты балконов и тёмные пояса окон ложатся на эту сетку). Башня — 20 этажей,
  «корона» до 67,4 м; кирпичная часть на рендере 10 — 17 этажей и терраса на крыше.
- **Камеры рендеров** подобраны по углам блока К (`tools/mi/fitcam.py`, ошибка 5–7 px из 4940).
  Сравнение «рендер / сайт» с тех же точек: `node tools/mi/shots.mjs build/cmp r10 r9`.

## Блок К (`blender/mi/block_k.py`)

- Подиум 1–3 этажей: витрины (импосты через 1,58 м), белые пояса, стекло 2-го этажа, кирпич 3-го
  этажа с окнами, парные белые лопатки на модуле башни 3,15 м, скруглённый торец к перекрёстку.
  Магазины за стеклом рисует само стекло (`Shop glass`: глубокие освещённые залы).
- 4-й этаж — кирпич под белым «потолком» башни на 15,23 м.
- Этажи 5–19: белая стена с проёмами глубиной 0,4 м ярусами по три этажа, между ярусами пояс 0,6 м;
  в проёмах окна (чёрные рамы, тёмный пояс на каждом этаже, импост, фрамуга), белые и деревянные
  панели, узкие ниши, ниши с тёплой светодиодной линией. Широкие и узкие проёмы меняются местами
  от яруса к ярусу — как на рендерах.
- Северо-восточный фасад: угловые балконы и угловое остекление у восточного угла, глубокая прорезь
  с балконами (под каждым тёплая линия), сквозь «корону»; деревянная лоджия на 11–13 этажах вокруг
  восточного угла.
- 20-й этаж отступает за раму: терраса с ограждением в каждом проёме, наклонные козырьки, сад на
  крыше (деревья видны над рамой, как на рендере 9). Тёплые линии по верху рамы и по углам башни.
- Кирпичная часть (северо-запад): 17 этажей, окна 2 × 2 створки с белыми подоконниками, на торце
  французские окна в нише, терраса с деревьями.

## Остальные блоки (`blender/mi/massing.py`)

Белые макеты: контур с генплана, высота по надписи (подиум 2 этажа, нижняя часть и башня),
бороздка на каждом этаже. Когда блок будет готов, его модуль строится как `block_k.py`, а ключ блока
добавляется в `FULL` в `blender/mi/config.py`.

## Сайт

- Блоки слева (на телефоне — полоса внизу, К первым), карточка справа, ракурсы «С улицы»,
  «С перекрёстка», «Сверху», «Крыша».
- Наведение и выбор блока — яркий контур и заливка. Камера к белому блоку подбирается снаружи
  комплекса, чтобы ничего не загораживало.
- Подписи блоков и зданий прячутся, если их закрывает другой блок.
- Время суток (открывается в 10:30: солнце с востока-юго-востока, как на рендере 10), ночью светятся
  окна, витрины, фонари и тёплые линии фасада. Кнопка-глаз прячет все панели.
- Высокое качество (компьютер): тени 8192, AO, отражения окружения в стекле блока К.

## Сборка и проверки

```bash
npm run dev -- --port 5196 &                       # сайт
tools/ab/py tools/mi/genplan.py                    # только если поменялся генплан
tools/ab/py tools/mi/plans.py                      # только если поменялись планы
blender/export_mi.sh                               # -> public/models/mi.glb, src/model/complex.json
tools/ab/py tools/mi/check_site.py                 # скамейки, люди, деревья, машины: 0 проблем
PYTHONPATH=.pylib-blender /Applications/Blender.app/Contents/MacOS/Blender -b build/mi.blend --python-use-system-env -P blender/mi_gaps.py   # дыры в оболочке блока К
node tools/mi/shots.mjs build/shots home corner street air top complex      # кадры
node tools/mi/shots.mjs build/cmp --size 1414x1000 r10 r9                    # камерами рендеров
node tools/mi/shots.mjs build/qa --ui block=A block=K                        # вид блока с панелями
npm run build                                      # dist/
```

`tools/ab`, `blender/ab`, `blender/complex` — общие инструменты и материалы из проекта «Али Бинокор»
(сайт им пользуется: `ab.site` — фонари и скамейки, `complex.geom` — построитель сеток).
Старые файлы интерфейса «Али Бинокор» для справки — в `_ab_old/`.
